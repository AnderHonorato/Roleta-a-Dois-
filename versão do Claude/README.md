# Roleta a Dois · versão do Claude

Implementação visual independente da versão Claude. Não usa o dado da versão GPT.

## Mecânica

1. A primeira roleta gira e escolhe a ação.
2. A segunda roleta gira novamente.
3. O segundo resultado é escolhido entre opções compatíveis com a primeira ação.
4. A combinação final aparece com animação.
5. O casal registra se fez ou pulou.
6. Pontuação e sequência são atualizadas.

## Visual

- Clean e editorial.
- Vermelho + roxo.
- Fundo escuro com brilho discreto.
- Serif para resultados e sans-serif para interface.
- Sem avatar VCG.
- Ícones próprios selecionáveis.
- Giro com desaceleração.
- Microinterações, glow, reveal, feedback e sons opcionais.
- Responsivo.
- prefers-reduced-motion.
